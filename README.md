## Описание 
Проект был реализован во время участия в хакатоне "Лидеры цифровой трансформации".  
Целью было создание модели, способной извлекать именнованные сущности из поисковых запросов.  
Для решения задачи использовалась модель RuBERT, дообученная на тренировочных данных.  
Одним из требований был запуск сервера и развертывание на нем docker контейнера.  
В результате готовая модель достигала показателя качества F1-Score - 0.9495.  
Что принесло 12 место из 61 в общем зачете.  


### Запуск сервера

- Скопировать папку ner-bert-docker-container
- Зайти в нее: cd ner-bert-docker-container
- Выполнить команду sudo docker build -t project-x5 .
- Выполнить команду sudo docker run -d -p 8000:8000 x5-ner-hackathon                                                             


### Обучение модели
- Сперва нужно предобработать данные, исполнив скрипты из папки refactor-data: порядок выполнения скриптов указан в их названии
- После можно обучать модель, скрипты для обучения находятся в папке training-model: порядок выполнения скриптов указан в их названии
- По завершении обучения и квантования весов будут созданы папки с tokenizer и самой моделью
- Квантование весов необходимо для ускорения инференса модели на сервере с CPU, с доступным GPU его можно не проводить, метрики качества в таком случае будут лучше
